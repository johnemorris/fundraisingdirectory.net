# Fundraiser Finder data gaps

The V1 Finder scores provider records only from structured fields already in the
repository. It can compare organization type, method, channel/format, product or
event acceptability, inventory model, upfront-cost category, effort category,
country-level availability, and documented product/service types.

The provider schema now expresses program-level participation minimums, timing,
requirements, and explicit program outcomes. The existing nine records have not
been newly researched, so these fields deliberately retain missing-data states.
The Finder currently serializes and scores approved structured outcomes; it does
not yet use the new eligibility or timing fields to change ranking. It continues
to lower confidence rather than manufacture a match when those inputs are not
documented. Passive/ongoing operation and exact ZIP/postal-code service areas
remain unstructured Finder gaps.

Commercial placement must remain independent of fit. Provider `affiliation` and
`editorial` fields are not serialized to the Finder page and are not inputs to
its scoring policy.
